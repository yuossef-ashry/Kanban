## 📖 About The Project

The idea behind Kanban comes from a simple concept:

> **Stop starting new work. Finish what is already in progress.**

Traditional production systems often used a **Push System**, where products were manufactured based on a predefined plan, even if they weren't needed yet.

Kanban introduced a different approach — the **Pull System**.

Instead of producing everything in advance, each stage requests only what it needs from the previous stage.

This same concept can be applied to software development and task management:

* 📝 **To Do** → Tasks waiting to be started
* ⚙️ **In Progress** → Tasks currently being worked on
* ✅ **Done** → Completed tasks

The goal is to keep work organized, reduce multitasking, and maintain a smooth workflow.

## 🔄 CRUD Operations

The application implements the basic **CRUD** operations:

### Create

Create a new task and add it to the Kanban board.

### Read

Retrieve and display saved tasks from LocalStorage.

### Update

Edit task information or change its current status.

### Delete

Remove tasks from the board and LocalStorage.
